# services/voice — Voice gateway (Phase 5)

(realtime speech-to-speech, or modular STT→agent→TTS for Tunisian Derja). Drives
the same agent orchestrator as text. See [docs/05-voice.md](../../docs/05-voice.md).

Not yet implemented — scaffolded in Phase 5. Opens with the Derja STT/TTS benchmark
spike (roadmap §Phase 5).
